HOW TO CONNECT WITH MONGODB COMPASS
================================================================

2. Click "New Connection"
3. Paste this connection string:
   mongodb://admin:admin_pass@localhost:27017/?authSource=admin

4. Click "Connect"

OR manually configure:
   - Hostname: localhost
   - Port: 27017
   - Authentication: Username/Password
   - Username: admin
   - Password: admin_pass
   - Authentication Database: admin

================================================================
DOCKER COMMANDS
================================================================

Start MongoDB:
  docker-compose up -d mongodb

Stop MongoDB:
  docker-compose stop mongodb

View MongoDB logs:
  docker logs admin-service-mongodb

Connect via mongo shell:
  docker exec -it admin-service-mongodb mongosh -u admin -p admin_pass --authenticationDatabase admin
