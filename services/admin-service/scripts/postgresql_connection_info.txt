================================================================
DOCKER COMMANDS
================================================================

Start PostgreSQL:
  docker-compose up -d postgres

Stop PostgreSQL:
  docker-compose stop postgres

View PostgreSQL logs:
  docker logs admin-service-postgres

Connect via psql:
  docker exec -it admin-service-postgres psql -U postgres -d admin_service

List databases:
  docker exec -it admin-service-postgres psql -U postgres -c "\l"
